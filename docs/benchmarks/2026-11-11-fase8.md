# Benchmark — Fase 8 (2026-11-11)

**Build:** Release, dependente de framework, win-x64 · **Instância:** pasta de dados isolada (`--data-dir`),
sem widget, janela principal aberta na página Finanças com 2 contas e 5 lançamentos.

| Situação | CPU / 30 s | Memória privada |
|---|---|---|
| Página Finanças aberta, parada (aba Contas) | **0 ms** | 97 MB |
| Editor de lançamento aberto com o cursor num campo | 328 ms | 109 MB |

- A página não tem timer próprio. O único timer (o "desfazer" de 10 s) só existe depois de uma exclusão e para
  sozinho.
- O custo com o editor aberto vem do cursor de texto do WPF piscando no campo em foco; some quando o campo
  perde o foco ou o editor fecha.
- Abrir o `finance.db` (verificação de integridade + leitura de tudo para a memória) não aparece no tempo de
  inicialização com poucos lançamentos. **Não medido ainda:** abrir e filtrar com 50 mil lançamentos (meta da
  proposta: < 150 ms e < 100 ms). Fica para a Fase 13, com dados gerados.
